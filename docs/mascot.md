# BookShelf マスコットキャラクター設定

## ブックロウ（Booklow）

本が大好きな、ちょっとおっとりしたフクロウの司書。

たくさんの本の中から、読みたい一冊を見つけるお手伝いをする、BookShelfの案内人。

## 1. 基本設定

| 項目 | 設定 |
| --- | --- |
| 名前 | ブックロウ |
| 英語表記 | Booklow |
| 名前の由来 | ブック ＋ フクロウ |
| モチーフ | フクロウ |
| 役割 | BookShelfの司書・案内人 |
| 性別 | 特に設定しない |
| 年齢 | 不詳 |
| 性格 | 温厚、知的、好奇心旺盛、少し天然 |
| 得意なこと | 本を探すこと、本の場所を覚えること |
| 好きなこと | 読書、本棚の整理、知らない本との出会い |
| 苦手なこと | 本に夢中になると時間を忘れること |

## 2. ビジュアルデザイン

デザインコンセプトは「かわいく、やさしく、シンプル」。

- **画風**：2Dフラットイラスト。立体感やリアルな質感を避ける。
- **体型**：頭と胴体が一体化した、丸くふっくらしたシルエット。
- **顔**：大きな丸眼鏡、黒目がちな目、小さな黄色いくちばし。
- **体**：やわらかい茶色。顔とお腹は薄いベージュ。
- **翼・足**：短く小さめ。威圧感を与えない。
- **小物**：緑色の本を抱えている。
- **表情**：基本は穏やか。驚き、喜び、困惑などのバリエーションを持つ。

## 3. 性格・キャラクター性

ブックロウは、自分が賢いことをひけらかさない司書。

膨大な蔵書を把握しており、頼まれた本を一生懸命探してくれる。本人はいつも真面目だが、少し間の抜けたところがあり、そのギャップが魅力。

名前はひどいダジャレだが、本人は特に気にしていない。

キャラクターの核は「頼りになるけれど、ちょっと抜けている」。

## 4. 表情・ポーズのバリエーション

| 状態 | 表情・ポーズ |
| --- | --- |
| 通常 | 本を抱えて穏やかに微笑む |
| 検索中 | 本をめくりながら調べる |
| 発見 | 目を輝かせて喜ぶ |
| 見つからない | 首をかしげて困る |
| 歓迎 | 翼を広げて出迎える |
| エラー | 眼鏡をずらして戸惑う |

## 5. アプリ内での役割

### 表示方法の想定

| 場所・状態 | 表示方法 |
| --- | --- |
| 通常画面 | ヘッダーに小さく配置 |
| 蔵書未登録 | 大きく表示して利用を案内 |
| 検索中 | 調べ物をしているポーズ |
| 検索結果なし | 首をかしげたポーズ |
| エラー | 困った表情でメッセージを補助 |
| PWAアイコン | 顔・丸眼鏡・本を中心にした簡略版 |

### セリフ例

- 「ようこそ、BookShelfへ！」
- 「本棚を探しています…」
- 「見つかりました！」
- 「その本は見つかりませんでした」
- 「まずは本棚を登録しましょう」

口調は丁寧で親しみやすく、過度なキャラクター語尾は使わない。

## 6. デザイン上のルール

- グラデーション、強い影、3D表現は使わない。
- 輪郭と色面を中心に構成する。
- 小さなサイズでもフクロウと認識できる。
- 丸眼鏡を最も重要な識別要素とする。
- 本を持たないポーズでも同じキャラクターに見える。
- 読書や検索の邪魔にならない控えめな存在感にする。

## 7. キャラクターの一文定義

> 「ブックロウ」は、丸眼鏡をかけた、ちょっとおっとりしたフクロウの司書。膨大な本棚から読みたい一冊を見つける、BookShelfの小さな案内人。

この設定を基本仕様として、PWAアイコン、通常立ち絵、状態別イラストを共通のデザインで展開する。
